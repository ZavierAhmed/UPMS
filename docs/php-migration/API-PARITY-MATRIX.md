This matrix inventories legacy routes as well as the active Simple V1 profile. Legacy management modules are deliberately blocked by Express with 403 LEGACY_DISABLED_IN_V1 in that profile; their presence is not permission to activate them. Exact request/response handlers, service method bodies, validation, permission predicates and source hashes are in [API-CONTRACT-INVENTORY.json](API-CONTRACT-INVENTORY.json). Service bodies include conditional permission checks and side effects; shared transaction/authorization helpers remain authoritative. JSON fields must retain their source spelling and types; DECIMAL and BIGINT are strings, INT flags/versions are numbers unless explicitly converted.

## Shared transport and errors

Management requires verified HTTPS, same-origin unsafe requests, application/json, 12 KiB bodies, HttpOnly/Secure/SameSite=Strict host cookies, and synchronizer CSRF tokens. Session/csrf is anonymous; session/login requires an anonymous CSRF session. Other endpoints require portal.access before CSRF, then endpoint permissions. Disabled or stale identities/expiry fail with 401; permission checks fail with 403. Idle expiry is 30 minutes, absolute expiry 8 hours. Forced rotation restricts business access.

Identity errors use {error:{code,reference}}. Simple V1 validation/400/409 adds message and optional fieldErrors/details from errors.js. Other shared codes: HTTPS_REQUIRED, ORIGIN_REJECTED, JSON_REQUIRED, INVALID_INPUT, REQUEST_TOO_LARGE, CSRF_REJECTED, AUTH_REQUIRED, SESSION_EXPIRED, ACCESS_DENIED, PASSWORD_CHANGE_REQUIRED, IDENTITY_UNAVAILABLE, IDENTITY_CONFLICT, INVALID_REFERENCE_OR_CONSTRAINT. Read contracts and representative errors are tested against actual Express JSON responses, ignoring only correlation UUID values.

Simple V1 reads lock identity_guard inside a database transaction, require administrator + matching v1_control.operator_id, and reject forced rotation. Business reads mutate no stock, documents, journals, counters or commands. Session expiry refresh and security audit writes are separate authentication effects. Writes require UUID command keys, immutable command results, canonical input fingerprints, READY gate, optimistic versions and row locks in deterministic item order. Rollback covers all posting effects and command receipts. Never substitute a simplified financial calculation.
