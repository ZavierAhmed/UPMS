# New Challan workflow

Sales exposes **New Challan** in its primary header, including the narrow mobile layout. It opens the original authorized creation form, retains native validation, saves through the original API and displays the saved draft at its canonical route.

The isolated populated browser case creates a synthetic challan, checks draft stock/receivable neutrality, explicitly confirms posting and verifies immutable refresh plus exactly one journal. It also checks populated classified ledger source navigation and return selection. No operational opening balances or postings were created in main or the preserved demo.

Read-generation guards prevent stale route responses from replacing a newer view. Competing actions remain disabled during pending reads. Cached unsaved forms survive internal navigation; reload/close protection warns the user. Draft cache is memory-only, not a promise of persistence after browser shutdown.
