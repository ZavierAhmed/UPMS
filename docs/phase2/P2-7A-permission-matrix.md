# Department authority

| Action | Sales/Dispatch | Inventory | Administrator | Accounts |
|---|---|---|---|---|
| Sanitized return/source/history read | Yes | Yes | Yes | Yes |
| Request create/post | Yes | No | Yes | No |
| Physical receipt to quarantine | No | Yes | Yes | No |
| Inspection / disposition submission | No | Yes | Yes | No |
| Exact approval/rejection | No | No | Yes | No |
| Approved disposition posting | No | No | Yes | No |
| Reconciliation | No | Yes | Yes | No |
| Accept synthetic policy | No | No | Yes | No |

Ten additive returns.* permissions. Additional document-kind posting permission is resolved under the identity guard before durable replay. Server checks do not rely on hidden controls. Existing session expiry/revocation, CSRF, Origin and body validation remain in force. Approval also requires shared business.approve and currently enabled Administrator/action authority; staff cannot self-approve. No old financial or inventory role rights are expanded.
