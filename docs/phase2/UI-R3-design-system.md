# Round 3 management design system

ActionButton and ActionToolbar share text labels, existing inline SVG icons, focus treatment, disabled state and busy feedback. Charcoal identifies create/save/submit, green approval/posting, red rejection/revocation, blue editing, amber warnings and neutral source/navigation actions. Icons are decorative; the text supplies the accessible name. Pending authorized reads disable competing workflow actions.

The sidebar and dashboard retain their established navigation/card patterns. Workflow headers expose primary actions; mobile headers stack them. Forms retain native labels, validation and original request serialization. Master forms group record information separately from saving. Financial confirmation and permission gates remain server authoritative.

Document summaries, accounting tables, readable evidence and collapsed activity replace technical-first presentation. Administrator diagnostics are explicitly labelled and closed by default. Public Unique Plastic Industry branding, graphite/orange/warm-white identity and assets are unchanged. No dependencies or published imagery were added.
